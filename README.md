# Java Daily Learning

This repository documents my programming learning journey through daily coding practice and problem-solving.

## Description

This project is created for Advanced Web Programming Practical No. 5 to practise Git version control and GitHub repository management.

## Goals
- Learn programming fundamentals.
- Practise Java and Python.
- Improve logical thinking.
- Track progress using Git and GitHub.

## Repository Structure
- `oneprogram.java` — a simple Java program.
- `python/hello.py` — a Python practice program.
- `.gitignore` — specifies files Git should ignore.

## Run the Java Program

Make sure a Java Development Kit (JDK) is installed. Open a terminal in this folder and run:

```bash
javac oneprogram.java
java oneprogram
```

## Git Commands Practised

`git init`, `git status`, `git add`, `git commit`, `git branch`, `git remote`, `git pull`, `git push`, and `git log`.
